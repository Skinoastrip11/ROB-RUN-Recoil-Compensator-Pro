## Burst curve

Compensation ramps over the first 300 ms of a burst, so the opening shots keep a natural climb and only the tail flattens. Ramp length is adjustable 100-500 ms.

## Calibration

1. Empty a magazine into a wall at 25 m.
2. Raise class strength until the pattern is a 1 m group.
3. Back off 5% for believability.

## Install

Admin loader, game, INSERT, F7 toggle.

## Troubleshooting

Pattern drifts up: strength up. Pattern shakes: strength down or ramp longer. Module silent: fire once after toggling.

Windows 10/11, Steam, EAC.
